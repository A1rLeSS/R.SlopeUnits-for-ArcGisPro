# R.slopeunits 斜坡单元 · ArcGIS Pro Add-in

> 版本：0.4（2026-10-25）  
> 适用：ArcGIS Pro 3.0–3.7 / .NET 6  
> 后端：GRASS `r.slopeunits.create` + `clean`（GRASS 8.5.0，便携 runtime 随包提供）

> 安装器会把 `Tools/` 部署到 `%LOCALAPPDATA%\BasinSlopeTools\tools` 并写入 `.tools_revision`；缺失时 Add-in 会从 `.esriAddinX` 自动解压，不依赖 AssemblyCache 中的 Tools 目录。

## 1. 功能

安装后，ArcGIS Pro 顶部出现 **“R.slopeunits 斜坡单元”** 选项卡，有四个按钮：

| 按钮 | 功能 |
|---|---|
| **生成斜坡单元** | DEM → GRASS `r.slopeunits.create + clean` → GeoPackage/GDB |
| **批量生成** | 多 DEM 批量，支持断点续跑 |
| **参数扫描** | 阈值/面积/CVAR/迭代组合扫描，支持断点续跑 |
| **质量报告** | 打开最近一次运行的质量报告窗口 |

插件不包含流域生成、流域—斜坡耦合、ML 等功能。

## 2. 安装

```text
output\00_交付包\BasinSlopeTools_Setup_0.4\BasinSlopeTools_Setup_0.4.exe
```

双击后点击“开始安装”。安装器自带 GRASS 8.5.0 runtime，不需要单独安装 GRASS。

静默安装/卸载：

```cmd
BasinSlopeTools_Setup_0.4.exe --silent
BasinSlopeTools_Setup_0.4.exe --uninstall
```

### 方式 B：便携 zip

```text
output\00_交付包\BasinSlopeTools_Portable_20261025.zip
```

解压后双击 `install.cmd`。

### 方式 C：仅 Add-in（开发机已装 GRASS）

1. 关闭 ArcGIS Pro；
2. 双击：

```text
D:\BasinSlopeCoupling\pro_addin\dist\BasinSlopeTools.esriAddinX
```

> 该文件是成品副本；重新编译后生成在 `pro_addin\BasinSlopeTools\bin\Release\net10.0-windows\`。

3. 重新打开 Pro。

## 3. 使用

点击 **生成斜坡单元**，填写：

| 参数 | 默认 | 说明 |
|---|---:|---|
| 输入 DEM | — | **投影 DEM，单位必须为米**；运行前检查 Nodata/异常值 |
| 输出 GeoPackage | — | 例如 `slope_units.gpkg` |
| GRASS grass85.bat | 自动 | 优先使用便携 runtime |
| DEM EPSG | 自动 | DEM 无坐标系或自定义坐标系时手动填写 |
| 参数预设 | 自定义 | `13m / 2km²`、`30m / 5km²`、`快速预览` |
| thresh | 250000 m² | 初始阈值 |
| areamin | 200000 m² | 最小面积 |
| areamax | 空 | 最大面积，可选 |
| cvmin | 0.25 | 坡向圆方差阈值 |
| rf | 2 | 阈值递减因子 |
| maxiteration | 50 | 最大迭代 |
| convergence | 5 | MFD 收敛因子 |
| SFD | 否 | 默认 MFD |
| cleansize | 25000 m² | 清理小单元面积（整数） |
| clean method | 快速（方法1） | 快速 / 条纹清理（方法2） / 详细清理（方法3） |
| 同时输出 GDB | 否 | 在 GPKG 旁生成 `slope_units.gdb` |

运行后：

- 输出 GeoPackage，包含 `AREA_M2`、`CVAR` 字段；
- 可选输出 `slope_units.gdb`；
- 生成 `<输出名>_quality_report.html/json/csv` 质量报告；
- 生成 `<输出名>_run_manifest.json` 参数清单；
- 生成 `%TEMP%\R_slopeunits_<时间>.log` 运行日志；
- 点击插件 **质量报告** 按钮可查看最新报告；
- 自动加载到当前地图（在 Pro 中运行时）。

## 4. GRASS 路径

默认查找：

```text
%LOCALAPPDATA%\BasinSlopeTools\runtime\grass\bin\grass85.bat
<Add-in>\runtime\grass\bin\grass85.bat
D:\OSGeo4W\bin\grass85.bat
D:\OSGeo4W\bin\grass.bat
C:\OSGeo4W\bin\grass85.bat
```

如果安装到其他位置，在工具参数里手动选择 `grass85.bat`。

## 5. 已验证

- 便携 GRASS 在独立目录下 `--version` 正常；
- 小 DEM：create + clean 成功，`CLEAN_STATUS=OK`，输出含 `AREA_M2`；
- clean 方法2、SFD 模式：成功；
- GDB 输出：成功生成 `slope_units.gdb\slope_units`；
- 错误 EPSG（DEM=32648，输入=4326）：被拒绝；
- 地理坐标系 DEM 被正确拒绝；
- 安装器 `--dry-run` / `--silent` / `--uninstall` / 重装：通过；
- 输出 GPKG 可被 ArcGIS Pro / GeoPandas 读取；
- 全分辨率 DEM 计算量较大，建议先用“快速预览”或小范围调参。
