# 安装与使用说明

[English](Installation.md) | [简体中文](安装说明.md)

> 版本 0.4.0 · ArcGIS Pro 3.0–3.7 · .NET 6 Add-in · GRASS GIS 8.5.0

## 1. 这个项目生成什么

本插件生成的是**斜坡单元**，不是流域多边形。它调用 GRASS `r.slopeunits.create` 和 `r.slopeunits.clean`，输出名为 `slope_units` 的图层，并附带 `AREA_M2`、`CVAR` 字段、运行清单和质量报告。

流域划分、流域—斜坡耦合不在当前插件范围内。

## 2. 下载与安装

从最新 Release 下载：

<https://github.com/A1rLeSS/R.SlopeUnits-for-ArcGisPro/releases/latest>

发布资产：

- `BasinSlopeTools_Setup_0.4.exe`：自带 GRASS 8.5 runtime 的 Windows 安装器；
- `BasinSlopeTools_Portable_20261025.zip`：便携包和 `install.ps1`；
- `SHA256SUMS.txt`：校验值。

安装步骤：

1. 关闭 ArcGIS Pro 和正在运行的 GRASS 分析任务；
2. 运行 `BasinSlopeTools_Setup_0.4.exe`；
3. 阅读并勾选许可协议；
4. 按 **欢迎 → 许可 → 确认 → 安装 → 完成** 完成安装；
5. 重新打开 ArcGIS Pro，打开 **“R.slopeunits 斜坡单元”** 选项卡；
6. 首次打开 Python Toolbox 时，按 Pro 提示允许运行第三方代码。

安装器不需要管理员权限，会检查 ArcGIS Pro 3.0–3.7、Pro 进程和至少 1.8 GB 可用空间。

### 静默安装 / 卸载

```powershell
.\BasinSlopeTools_Setup_0.4.exe --silent --accept-license
.\BasinSlopeTools_Setup_0.4.exe --uninstall
```

`--silent` 不带 `--accept-license` 时退出码为 `2`；安装失败为 `1`。日志在 `%TEMP%\BasinSlopeTools_Setup.log`。

## 3. 输入数据

- DEM 必须是**投影坐标系、米单位**；地理坐标系 DEM 会被拒绝；
- 支持 GeoTIFF、`.img`、ASCII Grid 和 **ESRI Grid**；
- ESRI Grid 请在文件对话框中选择 Grid 目录内的 `hdr.adf`，工具会自动解析父目录；
- `65535`、`-9999` 会在 GRASS 阶段通过 `r.null` 自动掩膜；
- 支持中文/非 ASCII 输入和输出路径（通过 ASCII 临时链接/副本）；
- 输出为 `*.gpkg`，可选 `<输出名>.gdb`。

## 4. 工具和参数

| 工具 | 用途 |
|---|---|
| 生成斜坡单元 | 单 DEM → GPKG/GDB、质量报告、可选地图图层 |
| 批量生成 | 多 DEM、断点续跑、`batch_summary.csv` |
| 参数扫描 | 阈值/面积/CVAR/迭代组合、断点续跑 |
| 质量报告 | 最新报告和上一份对比 |
| 关于/版权 | 版本、GPL、第三方许可和源码获取 |

主要参数：

| 参数 | 默认 | 说明 |
|---|---:|---|
| 输入 DEM | — | 投影 DEM；ESRI Grid 选择 `hdr.adf` |
| 输出 GeoPackage | — | `*.gpkg` |
| GRASS grass85.bat | 自动 | 内置 runtime 或自定义路径 |
| DEM EPSG | 自动 | 手动填写时必须与 DEM 一致 |
| 参数预设 | 自定义 | 13m/2km²、30m/5km²、快速预览 |
| thresh | 250000 m² | 初始阈值 |
| areamin | 200000 m² | 最小单元面积 |
| areamax | 空 | 可选最大面积 |
| cvmin | 0.25 | 坡向圆方差阈值 |
| rf | 2 | 阈值递减因子 |
| maxiteration | 50 | 最大迭代 |
| convergence | 5 | MFD 收敛因子 |
| SFD | 否 | 默认 MFD；开启为 D8 |
| cleansize | 25000 m² | 小单元清理面积 |
| clean method | 快速（方法1） | 快速 / 条纹（方法2）/ 详细（方法3） |
| 同时输出 GDB | 否 | 在 GPKG 旁生成 `<输出名>.gdb` |
| 自动符号化 | 单 DEM 默认开 | 按 CVAR 五级自然断点；依赖 GDB/地图 |
| 加载到地图 | 单 DEM 默认开 | 批量/扫描默认关闭 |

## 5. 输出

```text
<输出名>.gpkg
<输出名>.gdb/                 可选
<输出名>_quality_report.html
<输出名>_quality_report.json
<输出名>_quality_report.csv
<输出名>_run_manifest.json
%TEMP%\R_slopeunits_<时间戳>_<pid>.log
```

质量报告历史保存在 `%LOCALAPPDATA%\BasinSlopeTools\reports`，索引为 `quality_reports.json`；保留最近 50 份并清理更旧文件。

## 6. 生成效果综合评分

质量报告新增 **0–100 生成效果综合评分**和等级：

- CVAR 合格率（55%）：`CVAR <= cvmin` 的单元比例；
- 面积合格率（35%）：面积在 `areamin–areamax` 内（无 areamax 时只要求 `>= areamin`）的比例；
- clean 状态（10%）：`r.slopeunits.clean` 成功得满分。

等级：`>=85 优`、`>=70 良`、`>=55 合格`、`<55 需检查`。

该评分是**同一地区不同参数的相对比较指标**，不是绝对地形精度指标。详见 [QUALITY_SCORE.md](QUALITY_SCORE.md)。

## 7. 卸载

可使用 Windows“应用和功能”、安装器“卸载”按钮或：

```powershell
%LOCALAPPDATA%\BasinSlopeTools\uninstall.cmd
```

卸载会删除 Add-in、Tools、GRASS runtime、环境变量、质量报告历史和相关注册表项，但不会删除 DEM、GPKG/GDB 结果文件。

## 8. 已知限制

- 7,895 × 7,895 全分辨率 DEM 计算时间长，建议先用小范围或快速预览调参；
- 批量和参数扫描目前串行，没有取消 API；
- 符号化/加载地图依赖 Pro 地图会话，未纳入 CI；
- 安装器未签名，SmartScreen 可能提示；
- Pro 3.0–3.6 目标兼容，但未逐一实机验证。
